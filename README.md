# Kashini K — Student Portfolio Website

A responsive student portfolio built using HTML, CSS, and vanilla JavaScript. No framework or build step is required.

## Files
- `index.html` — page structure and content
- `css/style.css` — design, colors, responsive layout, and dark theme
- `js/script.js` — interactive features
- `images/` — optional images

## Run locally
1. Download and extract this ZIP file.
2. Open Visual Studio Code.
3. Choose **File → Open Folder** and select this folder.
4. Open `index.html`.
5. Right-click and select **Open with Live Server** if the extension is installed. Or double-click `index.html` in File Explorer to open it in your browser.

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `kashini-portfolio`.
2. Upload `index.html`, `css/`, `js/`, and any images to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose branch `main` and folder `/(root)`, then click **Save**.
5. Wait for the deployment to finish. GitHub will display your live URL, usually `https://YOUR-USERNAME.github.io/kashini-portfolio/`.

## Contact form note
The form validates the fields and displays a message, but it does not send or store messages. This project uses only front-end code.
